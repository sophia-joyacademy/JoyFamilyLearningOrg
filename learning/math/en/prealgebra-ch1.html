Whole Numbers

Name them, round them, and operate on them. Add, subtract, multiply and divide, with the notation, vocabulary and properties you will use all year.

Key terms

Whole numbers are 0, 1, 2, 3, … Counting numbers start at 1.

Number line

Numbers get larger going right. The point labeled 0 is the origin; the number paired with a point is its coordinate.

Place value system

The value of a digit depends on its position. In 3,507 the 5 means 500.

Rounding approximates a number to a chosen place.

Operation results
  • sum: result of adding
  • difference: result of subtracting
  • product: result of multiplying
  • quotient: result of dividing (dividend ÷ divisor)

Name a number
  1. From the left, name the number in each period, then the period name (not for ones).
  2. Separate periods with commas.
Write from words
  1. Spot the period words.
  2. Draw three blanks per period.
  3. Fill each period’s digits in place.

🎯 Rounding

Pick a place, then type a number or use ▲ ▼ on the ones and thousands digits. The target digit is purple; the digit to its right (the decider) is orange.

  1. Find the given place.
  2. Look at the digit to its right.
  3. 5 or more → add 1 to the place digit (9 becomes 0 and carries left). Less than 5 → leave it.
  4. Replace everything to the right with zeros.

    Properties

    Addition
    a + 0 = a

    Identity: adding 0 changes nothing.

    a + b = b + a

    Commutative: order of addends doesn’t matter.

    Multiplication
    a · 0 = 0

    Zero: anything times 0 is 0.

    a · 1 = a

    Identity: times 1 changes nothing.

    a · b = b · a

    Commutative.

    Division
    a ÷ a = 1, a ÷ 1 = a

    Properties of one (a ≠ 0 for the first).

    0 ÷ a = 0

    Zero divided by a nonzero number is 0.

    a ÷ 0 = undefined

    Never divide by zero!

    Subtraction and division are not commutative: 7 − 3 ≠ 3 − 7, and 12 ÷ 4 ≠ 4 ÷ 12.

    Strategies: step by step

    Add
    1. Line up place values.
    2. Add right to left, starting at the ones.
    3. If a column is more than 9, carry to the next place.
    Subtract
    1. Line up place values.
    2. Subtract right to left; borrow if the top digit is smaller.
    3. Check by adding the difference to the bottom number.
    Multiply
    1. Line up place values.
    2. Multiply the top number by each digit of the bottom, right to left, carrying as needed.
    3. Each new row starts with a placeholder 0.
    4. Add the partial products.
    Divide
    1. Divide the first digit(s) of the dividend by the divisor.
    2. Write the quotient above, multiply back, subtract.
    3. Bring down the next digit and repeat.
    4. Check: quotient × divisor (+ remainder) = dividend.
