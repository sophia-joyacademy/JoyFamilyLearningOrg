Solving Linear Equations

An equation is a balance. Whatever you do to one side, do to the other. Check whether a number is a solution, undo addition, subtraction, multiplication and division, handle variables on both sides, clear fractions and decimals, and turn words into equations.

Key terms

Solution of an equation

A value of the variable that makes a true statement when substituted into the equation.

Inverse operations

Operations that undo each other: addition ↔ subtraction, multiplication ↔ division.

Coefficient

The number multiplying the variable. In 5x the coefficient is 5.

Properties of equality

PropertyRule (a, b, c real numbers)
Subtractionif a = b then a − c = b − c
Additionif a = b then a + c = b + c
Divisionif a = b and c ≠ 0 then a/c = b/c
Multiplicationif a = b then a·c = b·c

                Strategies cheat sheet

                One-step and two-step
                1. Find what is done to x.
                2. Undo it with the inverse operation, on both sides.
                3. Undo adding or subtracting first, then multiplying or dividing.
                4. Check by substituting.
                General strategy
                1. Simplify each side: distribute, combine like terms.
                2. Collect the x terms on one side.
                3. Collect the constants on the other side.
                4. Make the coefficient 1 (divide, or multiply by the reciprocal).
                5. Check in the original equation.
                Special cases
                • x terms vanish and you get a true statement (5 = 5): every number is a solution.
                • x terms vanish and you get a false statement (3 = 7): no solution.
                Clearing fractions and decimals
                • Fractions: multiply every term by the LCD.
                • Decimals: multiply every term by 10, 100, 1000 … (the most decimal places).
