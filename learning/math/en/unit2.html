Key terms

System of equations

Two or more equations about the same variables, such as x + y = 7 and x − y = 1.

Solution of a system

An ordered pair (x, y) that makes every equation true. On a graph it is where the lines meet.

Substitution

Solve one equation for a variable, then replace that variable in the other equation.

Elimination

Add or subtract the equations (after multiplying if needed) so one variable disappears.

Inequality

Compares two expressions with <, >, ≤ or ≥. A constraint like “at most $60” is an inequality.

Solution set

All the values that make an inequality true. In one variable it is a range on the number line.

Boundary line

The line from the related equation. It is solid for ≤ and ≥ and dashed for < and >.

Solution region

The shaded half-plane holding every point that makes a two-variable inequality true.

System of inequalities

Two or more inequalities at once. Its solution is the overlap of their shaded regions.

📈 Solve a system by graphing

Graph both lines. The solution is the point where they cross. Edit the numbers in Ax + By = C for each line. Try parallel lines or the same line too.

    ✍️ Write a system from a story

    Name the variables, write one equation for each fact, then solve. Choose a type of story and change the numbers.

      🔁 Substitution

      Isolate a variable in one equation, substitute it into the other, solve, then go back for the second variable. Edit A, B and C in each equation.

        ➕ Elimination

        Make the coefficients of one variable the same size, then add or subtract the equations. Adding two true equations gives a new true equation with the same solution. Multiplying a whole equation by a number keeps its solution too.

          🔢 How many solutions?

          Compare slopes and y-intercepts of y = mx + b. Different slopes: one solution. Same slope, different intercept: none. Same slope and intercept: infinitely many.

            ↔️ Inequalities in one variable

            Solve ax + b (compare) c like an equation, but flip the symbol when you multiply or divide by a negative number. Then graph the solution set on a number line. Open circle for < and >; closed circle for ≤ and ≥.

              🎨 Inequalities in two variables

              Graph the boundary line, decide solid or dashed, test a point, then shade the side that holds the solutions.

                🎯 Systems of inequalities

                Shade each inequality. The solution is the overlap, where both are true. A point in the overlap satisfies every constraint at once.
