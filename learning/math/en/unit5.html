📖 Key terms

Exponential function

y=a\cdot b^{x}: start at a, multiply by b every step.

Initial value a

The output when x=0: the y-intercept (0,a).

Growth / decay factor b

b>1 grows. 0<b<1 decays. Decay factor =1-r; growth factor =1+r.

Common difference vs ratio

Linear: equal differences over equal intervals. Exponential: equal ratios.

Horizontal asymptote

The line the graph approaches but never reaches. For a\cdot b^x+d it is y=d.

Scientific notation

a\times10^{n} with 1\le|a|<10. Handy for huge and tiny numbers.
