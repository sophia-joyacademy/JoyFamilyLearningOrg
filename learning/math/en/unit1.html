Key terms

Variable · constant

A variable is a quantity that can change (a letter stands for it). A constant stays fixed.

Expression

Numbers, letters and operations with no equal sign, such as 24 + 4n. It names a quantity.

Constraint

A limit on what is possible, such as a budget. It can be written as an equation or an inequality.

Equation · solution

An equation says two expressions are equal. A solution is a value (or pair of values) that makes it true.

Equivalent equations

Equations that have exactly the same solutions. Legal moves turn an equation into an equivalent one.

Solve for a variable

Rearrange an equation so that one chosen variable is alone on one side.

Slope · rate of change

m = rise ÷ run = (y₂ − y₁) ÷ (x₂ − x₁). How much y changes when x increases by 1.

Intercepts

y-intercept (0, b): where the line crosses the y-axis. x-intercept (a, 0): where it crosses the x-axis.

Direct variation

y = kx. The ratio y ÷ x is always the same number k, and the line passes through the origin.

🎟️ Expressions, constraints and equations

Which quantities change and which stay fixed? Write an expression for the cost, then turn the budget into an equation. Edit the numbers.

    ✅ Solutions of an equation in two variables

    A solution of Ax + By = C is a pair (x, y). Test a pair; if it fails, keep x and find the y that works. Every point on the graph is a solution.

      ⚖️ Equivalent equations

      Apply a move to both sides of a x + b = c x + d and check whether the solution stays the same. Try multiplying by 0 or dividing by 0 to see what breaks.

        ⚠️ Why not divide by a variable? Take x² = 3x. It has two solutions, x = 0 and x = 3. Divide both sides by x and you get x = 3: the solution x = 0 is lost. Instead, move everything to one side and factor: x² − 3x = 0, so x(x − 3) = 0.

        🔧 Solve for a variable

        Choose which variable to isolate. Undo operations in reverse order, the same way you solve an equation. Edit A, B and C in the first two.

          📈 Connect an equation to its graph

          Rewrite Ax + By = C as y = mx + b. Then b is where the line starts on the y-axis and m is the rate of change: count rise and run.

            ✍️ Write the equation of a line

            Pick what you are given: slope and y-intercept, slope and a point, two points, or a table. The steps build y = mx + b and standard form.

              ∥ ⊥ Parallel and perpendicular lines

              Parallel lines have the same slope. Perpendicular lines have slopes that are negative reciprocals (their product is −1). Write the new line through a point.

                🔁 Direct variation

                y varies directly with x when y = kx. Give one pair (x, y) to find k, then predict y for another x.

                  Strategies cheat sheet

                  Model a situation
                  1. Decide which quantities change (variables) and which are fixed.
                  2. Write an expression for the quantity you care about.
                  3. Use the constraint to make an equation or inequality.
                  Equivalent equations
                  1. Add or subtract the same value on both sides.
                  2. Multiply or divide by the same non-zero value.
                  3. Never divide by a variable; never multiply by 0.
                  Write a line
                  • Two points: m = (y₂ − y₁) ÷ (x₂ − x₁).
                  • Plug m and a point into y − y₁ = m(x − x₁).
                  • Solve for y, or rearrange to Ax + By = C.
                  Special lines
                  • Parallel: same slope.
                  • Perpendicular: negative reciprocal slope.
                  • Direct variation: y = kx, passes through (0, 0).
