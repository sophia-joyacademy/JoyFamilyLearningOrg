Pre-Algebra · Chapter 11

Graphs

Plot points on the coordinate plane, test whether a point solves an equation, graph lines by plotting points or by finding intercepts, and measure how steep a line is with slope.

Key terms

Ordered pair

(x, y) gives the location of a point. The first number is the x-coordinate (left–right), the second is the y-coordinate (up–down).

Axes · origin

The x-axis is horizontal, the y-axis is vertical. They cross at the origin (0, 0).

Quadrants

The axes split the plane into four regions, numbered I–IV counter-clockwise starting at the upper right.

Linear equation

An equation of the form Ax + By = C (A and B not both 0). Its graph is a straight line.

Solution

An ordered pair (x, y) that makes the equation true. Every point on the line is a solution, and every solution is a point on the line.

Intercepts

Where the line crosses the axes. x-intercept (a, 0): y is 0. y-intercept (0, b): x is 0.

Slope

m = rise ÷ run. Rise is the vertical change, run is the horizontal change.

Horizontal line

y = b. Passes through (0, b). Slope is 0.

Vertical line

x = a. Passes through (a, 0). Slope is undefined.

📍 Plot a point

Type an ordered pair, or just click on the grid. Walk from the origin: first along x, then along y.

    ✅ Is it a solution?

    Substitute the point into the equation. If the equation is true, the point lies on the line.

      ✏️ Graph a line by plotting points

      Choose three x-values, find each y, plot the points and draw the line. Pick x-values that give whole-number y's.

        🎯 Graph with intercepts

        For Ax + By = C: let y = 0 to find the x-intercept, let x = 0 to find the y-intercept, then find a third point as a check.

          ⛰️ Slope from two points

          Slope tells how steep a line is: how far it rises for each step it runs. Move the points and watch the rise and run.

            🧭 Graph from a point and a slope

            Plot the point, then count the rise and run to find a second point. A negative rise goes down; a negative run goes left.

              Strategies cheat sheet

              Plot by points
              1. Find three solutions; organize them in a table.
              2. Plot the points; check that they line up.
              3. Draw the line and extend it with arrows on both ends.
              Intercepts
              1. x-intercept: let y = 0 and solve for x.
              2. y-intercept: let x = 0 and solve for y.
              3. Find a third point, plot all three, draw the line.
              Slope
              • m = rise ÷ run = (y₂ − y₁) ÷ (x₂ − x₁)
              • Up to the right: positive. Down to the right: negative.
              • Horizontal line: slope 0. Vertical line: undefined.
              Point and slope
              1. Plot the given point.
              2. Write the slope as rise ÷ run.
              3. Count the rise and run to mark a second point.
              4. Connect the points with a line.
