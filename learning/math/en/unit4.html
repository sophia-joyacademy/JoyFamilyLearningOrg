Functions

A function is a perfect machine: one input in, exactly one output out. Learn its notation, read its graph, shift and stretch it, find its domain and range, and follow sequences as they grow.

📖 Key terms

Function

A rule that gives exactly one output for each input.

Input / Output

Independent variable x goes in; dependent variable f(x) comes out.

Function notation

f(3)=11 means “when the input is 3, the output is 11”.

Intercepts

The y-intercept is f(0). A zero (x-intercept) is where f(x)=0.

Average rate of change

\frac{f(b)-f(a)}{b-a}: the slope between two points.

Transformation

Shift, stretch or reflect: a\,f(x-c)+d.

Domain / Range

All possible inputs / all possible outputs.

Arithmetic sequence

Add the same common difference d each time.

Geometric sequence

Multiply by the same common ratio r each time.
