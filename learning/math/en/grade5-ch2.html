📖 Key terms

Fraction

A number for equal parts of a whole. It also means division: 34 = 3 ÷ 4.

Numerator / denominator

The denominator names the size of the equal parts. The numerator counts how many parts.

Equivalent fractions

Same value, different names: 23 = 812. Multiply or divide top and bottom by the same number.

Common denominator

A shared denominator for two fractions. The least common multiple of the denominators is the easiest to use.

Improper fraction

The numerator is greater than or equal to the denominator: 74.

Mixed number

A whole number and a fraction together: 134. Same value as 74.

⚖️ Comparing fractions · 分数的大小比较

Compare the amounts, not just the digits. Use equal parts, number lines, benchmarks, and equivalent fractions to explain why one fraction is greater than another. · 比较的是分数表示的大小，而不只是数字。可以借助相同大小的份、数轴、基准数和等值分数，解释分数为什么更大。

Same denominator · 相同分母的分数比较

Start with 25 and 35. Change the numerators or the shared denominator and watch what happens. · 先看 25 和 35。修改分子或共同的分母，观察分数的大小如何变化。

Try it · 试试看

Think together · 一起想一想：

  • How many equal parts is each whole divided into? · 两个整体都被平均分成了几份？
  • Are the pieces the same size? · 每一份的大小相同吗？
  • Which fraction has more pieces? · 哪个分数表示的份数更多？
  • What can we conclude when denominators are the same? · 分母相同时，我们可以得出什么结论？
When the denominators are the same, the fraction with the greater numerator is greater.
分母相同，分子越大，分数越大。

Same numerator · 相同分子的分数比较

This is a chance to look beyond the size of the denominator: when the numerator stays the same, the pieces get smaller as the whole is divided into more parts. · 这一步要特别留意：分子相同时，不能只看哪个数字大。整体分得越多，每一份就越小。

Imagine two identical cakes. One is shared equally among 3 people; the other is shared equally among 8. Which person gets a larger piece, and why? · 想象两个一样大的蛋糕：一个平均分给3个人，一个平均分给8个人。哪一个人分到的蛋糕更大？为什么？

Fractions on a number line · 利用数轴理解分数

A fraction is a number, not only a piece of a cake. Mark fractions on a number line and explain where each one belongs. · 分数不只是蛋糕的一部分，它本身也是一个数。请把分数标在数轴上，并说说每个分数应该放在哪里。

Explore equivalent fractions · 探索等值分数

Each number line shows one whole. Choose how many equal parts to divide it into, then choose two numerators on each line. Look for fractions whose points line up vertically. · 每条数轴都表示一个整体。选择把整体平均分成几份，再为每条数轴选择两个分子。观察哪些分数的点在竖直方向上重合。

Compare with one-half · 与二分之一比较

One-half is a useful benchmark. Adjust each fraction and compare its point with the marked 12 on its number line. You can reason about some fractions without finding a common denominator. · 二分之一是一个很有用的基准数。修改分数，观察它在数轴上的位置与标出的 12 相比如何。有些分数不需要通分也能比较。

Try two fractions · 试试比较两个分数

Choose a numerator and denominator for each fraction. The orange dashed mark on both number lines is always 12. · 分别选择两个分数的分子和分母。两条数轴上的橙色虚线都固定表示 12。

Decide whether each fraction is less than, equal to, or greater than 12. Try to explain without converting to a common denominator. · 判断每个分数小于、等于还是大于 12。试着不通分，解释你的想法。

Challenge · 挑战：Without using a common denominator, compare 37 and 58. · 不通分，比较 37 和 58。

Show one way to reason · 查看一种推理方法

37 is less than one-half because half of 7 is 3 1/2. 58 is greater than one-half because half of 8 is 4. Therefore, 37 < 12 < 58. · 37 小于二分之一，因为7份的一半是3份半；58 大于二分之一，因为8份的一半是4份。因此 37 < 12 < 58。

Equivalent fractions · 等值分数

Start with one-half. Fold, draw, or shade a shape; then divide each half into 2, 3, 4, or 5 equal pieces. What changes? What stays the same? · 从二分之一开始。通过折纸、画图或涂色，再把每一半平均分成2份、3份、4份或5份。什么变了？什么没有变？

12=24

Make an equivalent fraction · 生成等值分数

Choose a fraction, then multiply both its numerator and denominator by the same number. Watch the shaded amount stay the same. · 选择一个分数，再把它的分子和分母同时乘以同一个数，观察涂色部分的大小保持不变。

Remember · 记住：Multiplying only the numerator or only the denominator usually changes the value. To keep the fraction equal, multiply both by the same nonzero number. · 只乘分子或只乘分母，通常会改变分数的大小。要保持分数相等，分子和分母必须同时乘以同一个非零数。

  • There are more pieces after we divide each part again. · 每一份再分之后，份数变多了。
  • The number of shaded pieces also increases. · 涂色的份数也增加了。
  • The actual shaded amount does not change. · 涂色部分实际表示的大小没有改变。
After exploring, state the rule · 探究后，再来总结规律

To make an equivalent fraction, multiply or divide the numerator and denominator by the same nonzero number. For example, 12 = 1×22×2 = 24 = 36 = 48 = 510. · 要得到等值分数，分子和分母同时乘或除以同一个非零数。例如：12 = 1×22×2 = 24 = 36 = 48 = 510。

Unlike numerators and denominators · 分子、分母都不同的分数比较

Compare 23 and 34. To compare them fairly, rename both using twelfths: 12 is a common denominator for 3 and 4. · 比较 23 和 34。为了公平比较，可以把它们都改写成以十二为分母的分数：12是3和4的公分母。

23 = 812<34 = 912

23 = 812 < 912 = 34

Common denominator · 公分母：Rewrite the fractions as equivalent fractions with the same denominator. Then compare the numerators. This builds on the equal-sized parts we have already explored. · 把分数改写成分母相同的等值分数，再比较分子。这样比较时，每一份的大小就相同了。
We compare by reasoning about equal parts—not by memorizing cross-multiplication.
我们通过理解相同大小的份来比较，而不是只记交叉相乘的步骤。

🚧 Common traps

Don't add denominators

12 + 13 = 56, not 25. Make the denominators the same first, then add only the numerators.

Change top and bottom together

To make 34 into twelfths, multiply both numbers by 3: 912. Changing only the denominator changes the value.

Borrowing in mixed numbers

416 − 156: borrow 1 whole = 66, so 376 − 156 = 226 = 213.

Simplify the answer

68 is correct but not finished. Divide top and bottom by 2 to get 34.
