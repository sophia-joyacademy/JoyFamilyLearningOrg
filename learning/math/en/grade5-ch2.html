📖 Key terms

Fraction

A number for equal parts of a whole. It also means division: 34 = 3 ÷ 4.

Numerator / denominator

The denominator names the size of the equal parts. The numerator counts how many parts.

Equivalent fractions

Same value, different names: 23 = 812. Multiply or divide top and bottom by the same number.

Common denominator

A shared denominator for two fractions. The least common multiple of the denominators is the easiest to use.

Improper fraction

The numerator is greater than or equal to the denominator: 74.

Mixed number

A whole number and a fraction together: 134. Same value as 74.

🚧 Common traps

Don't add denominators

12 + 13 = 56, not 25. Make the denominators the same first, then add only the numerators.

Change top and bottom together

To make 34 into twelfths, multiply both numbers by 3: 912. Changing only the denominator changes the value.

Borrowing in mixed numbers

416 − 156: borrow 1 whole = 66, so 376 − 156 = 226 = 213.

Simplify the answer

68 is correct but not finished. Divide top and bottom by 2 to get 34.
