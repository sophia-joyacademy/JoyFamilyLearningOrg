Integers

Numbers below zero. Learn opposites and absolute value, then add, subtract, multiply and divide integers, and solve equations with them.

Key terms

Integers

Counting numbers, their opposites, and zero: … −3, −2, −1, 0, 1, 2, 3 …

Negative number

A number less than zero. It sits to the left of 0 on the number line.

Opposites

Two numbers the same distance from 0 on opposite sides of 0, such as 5 and −5.

Absolute value

The distance of a number from 0 on the number line. It is never negative: |−5| = 5 and |5| = 5.

Positive counter

+ stands for +1. It is purple in the labs below.

Negative counter

− stands for −1. It is orange. One of each makes a neutral pair with value 0.

Same signs
  • Add the absolute values.
  • Keep the sign. (−5) + (−3) = −8.
Different signs
  • Subtract the smaller absolute value from the larger.
  • Use the sign of the number with the larger absolute value. −5 + 3 = −2.

    Addition Property

    If a = b, then a + c = b + c.

    Subtraction Property

    If a = b, then a − c = b − c.

    Division Property

    If a = b and c ≠ 0, then a ÷ c = b ÷ c.

    Strategies cheat sheet

    Add integers
    1. Same signs: add the absolute values and keep the sign.
    2. Different signs: subtract the absolute values.
    3. The answer takes the sign of the number with the larger absolute value.
    Subtract integers
    1. Change subtraction to adding the opposite: a − b = a + (−b).
    2. Then follow the rules for adding.
    3. Not enough counters to take away? Add neutral pairs.
    Multiply & divide
    1. Multiply or divide the absolute values.
    2. Same signs → positive. Different signs → negative.
    3. Times or divided by −1 gives the opposite.
    Is it a solution?
    1. Substitute the number for the variable.
    2. Simplify both sides.
    3. True statement? It is a solution. False? It is not.
    Solve a one-step equation
    1. Find the operation done to x.
    2. Do the opposite operation to both sides (add ↔ subtract, multiply ↔ divide).
    3. Simplify, then check.
    Application problems
    1. Identify what you are asked to find.
    2. Write a phrase that gives the information.
    3. Translate the phrase to an expression.
    4. Simplify the expression.
    5. Answer with a complete sentence.
